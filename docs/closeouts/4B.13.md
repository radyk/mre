-- nights and weekends included -- and add_no_overlap enforces it, so a

WOULD HAVE STAYED INVISIBLE.

FIXED, and confirmed on the re-minted board: ORD-000011 now renders 3 pieces
with its 4320 minutes of pauses visible, and 0 chunks anywhere on the board

4. A METHOD NOTE WORTH KEEPING
======================================================================

THE FIRST HEAD COMPARISON WAS WRONG, AND THE WAY IT WAS WRONG IS REUSABLE.
Checking whether a failure pre-existed, a worktree was created at HEAD and the
test PASSED there -- suggesting a regression. It was not. A git worktree does
not carry untracked files, so .env.local was absent and the test took the
other branch entirely. Copying .env.local in reproduced the failure at HEAD.
Any pre-existing check on this repo must carry .env.local into the worktree,
or it measures the key's absence instead of the code.

Related: the first re-mint of the exam world silently produced the OLD merged
bars, because --register submits to the RUNNING dev API, whose process still
held pre-change code. The dev API must be restarted before a re-mint is
treated as evidence about changed behaviour.
