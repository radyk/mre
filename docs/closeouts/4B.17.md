the Read tool, then reverted with `git checkout --` and re-appended in Python
with an explicit `encoding="utf-8"`. **Every file this session touched was then
checked for the three mojibake signatures, all eight clean.** For an append-only
document the near-miss is the point: the corruption was in the one file the hard
rules say must never be rewritten, and the only reason rewriting it was
legitimate is that nothing had been committed yet.
