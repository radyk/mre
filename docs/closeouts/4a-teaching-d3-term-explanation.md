### R1 — the pre-commit currency hook

Four named occurrences of the corpus-staleness class (4B.33, (c2), the
shared-body census micro-session, (e2)), and the remedy written down each time
was *"remember to rebuild"*. **Restraint is not a mechanism** — R-CM1's own
words, one rule over.

`tools/hooks/pre-commit` checks the **staged** docs against the committed index.
Installed by `git config core.hooksPath tools/hooks` so the hook is **committed
and reviewable** rather than living in one clone. Bypass is `--no-verify`, git's
own door and the only one — building a second would be a way to turn the guard
off without saying so in the reflog.

**Proven both ways.** A staged stale doc: exit 1, the block printed, and
`git log` confirms the commit did not land. A clean tree: exit 0.

**Its own first draft failed open**, and that is recorded because it is the
species: it read `payload["documents"]` where the key is `docs`, so it would have
crashed into its own SKIPPED branch and reported everything current forever. It
now calls the corpus's own `doc_fingerprints()` — the definition the currency
test uses.

## 9. What a summary would undersell

**That the census moved the design, and the brief's framing was the thing it
moved.** The session was scoped as "two refusals, find the seams, prove there is
no third". There are seven, and the founder's two are the *rarest* — one hit
each out of twenty-five. The real finding is that fifteen of twenty-five term
questions were already being answered, fluently, by a tier with no obligation to
cite a definition of our own vocabulary. The two visible refusals were the least
of it; they were just the only part a planner could see going wrong. A summary
saying "the product could not explain its own words" describes the symptom the
founder reported, not the thing the count found.

**That the trigger contract is the whole ruling, and it is a refusal.** The
easy version of this feature is a glossary the planner can query. That is a
documentation browser, and it would answer "what is a bottleneck" with our
authority on a word we did not choose. What makes this defensible is the part
that says *no*: we explain words **we said**, on **this board**, and the memory
of having said them dies with the version. Three of the four measured arms are
the route declining to answer.

**That two instruments lied to me before their subjects did, and both were
caught the same way.** The vocabulary census counted the harness's own sidecar
lines as product speech, which would have shipped `pinned` into the edition at
2.6× its real frequency. The currency hook read the wrong JSON key and would
have reported every commit current, forever, while looking like a working guard.
Neither was found by reasoning about the code; both were found by checking what
the thing actually returned on real input. **(d.2) named this class — "a zero
produced by an instrument that cannot see the value is not a zero" — and it
appeared twice more in the session immediately after, in code written by someone
who had just written that sentence down.**

**That the exam's own guards found this session's copy, twice.** `dead-door`
caught a glossary door that reads perfectly and goes nowhere. The negative
controls caught a control of mine that reverted something its guard did not
depend on. Neither was a product defect; both were new work failing an existing
check, which is the return on having built the checks.
